You are a senior brand and UI designer.

Using:
- The Design Language Guide and tokens,
- The chosen color palette and hero visual concept,
- The wireframe layout (STEP 4),
- The component and section patterns (STEP 5),

Task:
Create a full-page visual design specification for the Primordial website.

Output:

1) Art direction summary:
   - 1–2 paragraphs covering:
     - overall tone and mood
     - primary vs secondary color usage
     - typographic hierarchy (how headings vs body vs meta look)
     - how the page should feel compared to generic SaaS sites.

2) Section-by-section visual spec:
   For each section:
   - background treatment:
     - which color token / gradient / motif is used.
   - text hierarchy:
     - which text tokens for heading, subheading, body, captions.
   - motif usage:
     - where and how dots / grids / lines / frames appear.
   - special visual elements:
     - any blocks, highlights, callouts.

3) Motif rhythm:
   - Explain how recurring motifs appear at least 3 times across the page:
     - hero area
     - at least one mid-page section
     - footer or contact area.
   - Ensure they remain low-contrast and never reduce readability.

4) Interaction & motion:
   - Define hover / focus states for:
     - primary and secondary buttons
     - links
     - any interactive tags or labels.
   - Describe any subtle scroll-related effects (e.g. slight fade-in, parallax-like shifts) while keeping performance in mind.

5) Responsive behavior:
   - High-level guidance for mobile vs desktop:
     - stacking order of elements
     - padding changes
     - typographic scale adjustments
     - how hero visual crops or simplifies on small screens.

Self-check:
- 3 ways this visual spec remains faithful to the Figma design language and avoids generic SaaS aesthetics.
- 2 weak spots where it might still feel generic, with concrete suggestions to refine them.
